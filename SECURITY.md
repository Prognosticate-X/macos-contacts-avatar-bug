# Security Policy

## Reporting Security Issues

We take the security and privacy of macOS users seriously. 

This repository contains diagnostic research, reproduction logs, and open-source verification scripts related to the macOS 27 Contacts avatar reversion bug. All logs provided in this repository are strictly sanitized to redact personal names, emails, phone numbers, account tokens, and machine identifiers.

If you discover a security vulnerability or privacy concern with any tool or sample in this repository, please report it:
- Open an Issue: [GitHub Issues](https://github.com/Prognosticate-X/macos-contacts-avatar-bug/issues)
- Or contact the maintainer directly via GitHub profile.
